# 🏥 Clínica Médica – Página de Agendamento de Consultas

Este projeto consiste em uma página simples e responsiva para o agendamento de consultas médicas. Desenvolvido como parte do **Projeto Integrado de Desenvolvimento Web**, o sistema simula a interface que um paciente utilizaria para agendar uma consulta, informando seus dados e escolhendo data e horário disponíveis.

---

## 📌 Funcionalidades

- 📅 **Seleção de data** com campo do tipo `date`
- ⏰ **Lista de horários disponíveis**, gerada dinamicamente em JavaScript
- 🧍‍♂️ **Formulário do paciente** com campos de nome, telefone e e-mail
- ✅ **Validação de campos obrigatórios** com alertas
- 📃 **Resumo do agendamento** exibido na tela após a confirmação
- 📱 **Layout responsivo**, adaptado para celulares, tablets e desktops
